# B232270042 Лаборатори1 — UI автомат тест / Playwright

Энэхүү лабораторийн ажлаар Playwright ашиглан веб интерфэйсийн автомат тест бичиж, ажиллуулж туршсан.
Тест хийх вебээр [SauceDemo](https://www.saucedemo.com/) сайтыг ашигласан бөгөөд Playwright болон TypeScript дээр нийт 3 тест бичсэн.

## Хийсэн тестүүд

- Зөв хэрэглэгчийн нэр болон нууц үгээр амжилттай нэвтрэх тест
- Буруу нууц үг ашиглах үед алдааны мэдээлэл зөв гарч байгаа эсэхийг шалгах тест
- Амжилттай нэвтэрсний дараа барааг сагсанд нэмэх үйлдлийн тест

Тестүүдэд Playwright-ийн `getByRole`, `getByPlaceholder`, `getByText` зэрэг locator-ууд болон `expect` assertion-уудыг шууд байдлаар ашигласан. Мөн тестүүдийг ажиллуулсны дараа HTML report үүсгэж, Trace Viewer ашиглан тестийн алхмуудыг шалгаж үзсэн.
HTML report-ийг my-first-test/HTML_Report.html -д байршуулсан
Report болон үзүүлэлтүүдийг хаана байршуулах тал дээр тогтмол directory байвал хянах багшид илүү ашигтай байна гэж бодож байна. Одоогийн байдлаар trace viewer хэрэглэж туршисан боловч илүү байдлаар нэмэлт тайлагнах зүйл хийгээгүй байгааг анхаарна уу!

## Нэмэлт тулгарсан асуудал

Оюутан B232270042 би fedora хэрэглэдэг, өмнө нь ажлын чанараар хэрэглэж байсан тул WebKit хэрэглэх боломжгүй байж таарлаа, энэ нь асуудалтай бол, заавал шаардлагатай distro бичиг баримт дээр зааж өгнө үү! Баярлалаа.

## Тест ажиллуулах

Playwright browser-уудыг суулгах:

```bash
npm install
npx playwright install
```
test-үүдийг ажиллуулах:
```bash
npx playwright test
```
html-report байдлаар харуулах:
```bash
npx playwright show-report
```


## Playwright болон Selenium-ийн ялгааны талаарх ажиглалт

Playwright болон Selenium нь хоёулаа веб хөтчийн автомат тест хийхэд ашиглагддаг нээлттэй эхийн хэрэгслүүд юм.
Playwright-ийн надад хамгийн ойлгомжтой санагдсан давуу тал нь элемент бэлэн болох хүртэл автоматаар хүлээдэг auto-wait боломж байлаа.
Selenium дээр ийм нөхцөлд explicit wait-ийг гараар тохируулах шаардлага илүү их гардаг.

Playwright дээр browser-уудыг нэг командаар суулгах боломжтой байдаг нь анхны тохиргоог хялбар болгож байна.
Мөн `getByRole`, `getByText`, `getByPlaceholder` зэрэг locator-ууд нь XPath ашиглахаас илүү уншихад ойлгомжтой санагдсан.
Playwright-ийн Codegen нь browser дээр хийсэн үйлдлийг шууд тестийн код болгон харуулдаг тул тест бичиж эхлэхэд хэрэгтэй боломж юм.

Trace Viewer нь тестийн алхам бүрийг шалгаж, алдаа гарсан хэсгийг олоход тохиромжтой санагдсан.
Selenium нь илүү олон жил ашиглагдсан тул том ecosystem буюу холбогдолтой багаж хэрэгсэл илүү байдаг нь давуу талтай санагдлаа.
Энэ лабораторийн хувьд Playwright нь тохируулахад болон UI автомат тест бичихэд харьцангуй энгийн, ойлгомжтой санагдсан.
