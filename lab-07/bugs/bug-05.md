# BUG-05: "Нийт ном" тоолуур хүснэгтийн номын тоотой таарахгүй байна

**Орчин:** Уншлагын жагсаалт v2.0, Mozilla Firefox 157.0, Fedora Linux, 2026-10-20  
**Урьдчилсан нөхцөл:** Аппыг шинээр асаасан, анхны 3 номтой.

## Дахин гаргах алхам

1. Аппыг шинээр асаана.
2. Нүүр хуудсыг нээнэ.
3. Хүснэгтийн номын мөрүүдийг тоолно.
4. Доод хэсгийн **Нийт ном** утгатай харьцуулна.

## Хүлээгдэж байсан

Specification-ийн дагуу **Нийт ном** тоолуур хүснэгт дэх номын тоотой тэнцүү байх ёстой.

## Бодит үр дүн

Fresh app дээр хүснэгтийн номын тоо болон **Нийт ном** тоолуур зөрж байна.
