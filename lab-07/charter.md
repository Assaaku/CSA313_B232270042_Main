# Charter

**Судлах:** Уншлагын жагсаалт аппын үндсэн ажиллагаа болох ном нэмэх, хайх, устгах, мэдээлэл харуулах болон API-ийн алдаатай оролтод үзүүлэх хариуг судална.

**Ашиглан:** GUI дээр энгийн болон буруу оролтууд турших, хайлт болон товчлууруудыг шалгах, мөн curl ашиглан API руу хэвийн бус хүсэлт илгээнэ.

**Илрүүлэх:** validation-ийн алдаа, буруу мессеж, хайлтын зөрүү, UI-ийн харагдах байдлын асуудал болон API-ийн буруу HTTP хариуг илрүүлэхийг зорилоо.

## Сонгосон аялалууд

### Supermodel

Аппын UI, товч, хүснэгт, мессеж болон хэрэглэгчийн харж байгаа мэдээллийг шалгана. Энэ аппын үндсэн ажиллагааны ихэнх нь browser UI дээр харагддаг тул энэ аяллыг сонгосон.

### Saboteur

API руу curl ашиглан malformed эсвэл хэвийн бус хүсэлт илгээж error handling-ийг шалгана. Specification-д буруу JSON хүсэлт HTTP 400 буцаах ёстой гэж тодорхой заасан тул API түвшний согог илрүүлэхэд тохиромжтой.
